\# NEXLINK – ISP Network Infrastructure



\## Project Overview

NEXLINK is a practical ISP Network Infrastructure project developed using Huawei eNSP. This project demonstrates enterprise network design, routing, switching, VLAN segmentation and network services.



\## Network Technologies

\- Huawei eNSP

\- OSPF Routing

\- eBGP Routing

\- VLAN 10, 20, 30

\- Trunk and Access Ports

\- Router-on-a-Stick

\- DHCP Server

\- IP Addressing and Subnetting



\## Network Devices

\- R1 – ISP Core

\- R2 – ISP Distribution

\- R3 – Upstream ISP

\- R4 – Customer Gateway

\- SW1, SW2, SW3 – Access and Distribution Switching



\## VLAN Design



| VLAN ID | Name | Network |

|---|---|---|

| 10 | CORPORATE | 192.168.10.0/24 |

| 20 | HOME | 192.168.20.0/24 |

| 30 | BUSINESS | 192.168.30.0/24 |



\## Project Objectives

\- Design an ISP network infrastructure.

\- Configure dynamic routing using OSPF and eBGP.

\- Implement VLAN segmentation.

\- Configure inter-VLAN routing.

\- Provide automatic IP addressing using DHCP.

\- Practice real-world networking concepts.
